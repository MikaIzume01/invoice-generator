# Automated Invoice Generator (Aplikasi Generator Faktur & Nota Otomatis)

Aplikasi web berbasis Python Flask untuk pembuatan faktur, nota, dan manajemen penagihan bisnis secara otomatis dengan penyimpanan database lokal.

## 🚀 Fitur
- Pembuatan faktur/nota instan dengan kalkulasi total otomatis.
- Tampilan profesional siap cetak / PDF via `@media print`.
- Manajemen daftar klien dan riwayat transaksi.

## 🛠️ Tech Stack
- **Backend:** Python, Flask, SQLite / SQLAlchemy
- **Frontend:** HTML5, CSS3 (Responsive Design)

## ⚙️ Cara Menjalankan
1. Install dependensi:
   ```bash
   pip install flask
   ```
2. Jalankan aplikasi:
   ```bash
   python app.py
   ```
3. Buka di browser: `http://127.0.0.1:5000`
